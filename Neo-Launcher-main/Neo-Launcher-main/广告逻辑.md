# 下载器

## 一、首次启动逻辑

* **启动页**（广告预加载3s，无论是否加载成功）
    * ➔ **设置launcher**（无论是否设置）
        * ➔ **广告是否加载成功**
            * **是** ➔ 首次开屏广告 ➔ 引导页（1和2、2和3之间加入全屏广告） ➔ 文件存储权限页（文件授权页信息流） ➔ 首次插屏 ➔ 下载器应用主页
            * **否** ➔ 显示loading（3s）
                * *分支1*：广告加载成功 ➔ （跳转至）首次开屏广告
                * *分支2*：广告加载失败/超时 ➔ （跳转至）引导页（1和2、2和3之间加入全屏广告）

---

## 二、设置launcher弹窗展示时机（首次未设置时）

* **1、活跃用户启动** ➔ 下载器主页 ➔ 设置launcher弹窗
* **2、首次二级页返回**（后续每3次返回展示1次弹窗）
    * 1、网页返回
    * 2、书签返回
    * 3、历史返回
    * 4、隐私文件返回
* **3、应用切回**

---

## 三、广告展示逻辑

* **1、首次开屏** * ➔ 启动页（广告预加载3s，无论是否加载成功） ➔ 设置launcher（无论是否设置） ➔ 广告是否加载成功
        * **是** ➔ 首次开屏广告 ➔ 引导页（1和2、2和3之间加入全屏广告）
        * **否** ➔ 显示loading（3s）
            * *分支1*：广告加载成功 ➔ （跳转至）首次开屏广告
            * *分支2*：广告加载失败/超时 ➔ （跳转至）引导页（1和2、2和3之间加入全屏广告）
* **2、引导页全屏广告**
    * ➔ 处于引导页1和2、2和3之间（引导页点击next或者左右滑动时显示，广告滑动/点击关闭显示下一个引导页）
* **3、文件存储权限页信息流**
    * ➔ 同时加载首次插屏
* **4、首次插屏**（以下三种操作均会触发后续判断）
    * 文件授权成功
    * 文件授权失败
    * 点跳过
    * *(以上操作触发判断)* ➔
        * *情况A*：广告加载成功展示：首次插屏 ➔ 下载器主页
        * *情况B*：广告加载失败或超时 ➔ 下载器主页
* **5、活跃开屏**
    * ➔ 启动页（最多等待12s广告加载）
        * *情况A*：广告加载成功展示：活跃开屏 ➔ 下载器主页
        * *情况B*：广告加载失败或超时 ➔ 下载器主页
* **6、通用插屏**
    * 1、二级页返回
    * 2、网页搜索
    * 3、下载成功
    * 4、移动到隐私文件夹按钮点击
    * 5、删除按钮点击
* **7、主页信息流**
    * ➔ 搜索框与书签/历史布局控件之间
* **8、底部banner**
